# BlockTracer

A static block explorer produced by an ingest / process / publish pipeline, where
every transaction can carry a full time-travel debugging trace generated by
CodeTracer's recorders. The browser reads **static files and nothing else** — no
API, no database, no per-request compute.

The design and the milestone plan live in `codetracer-specs/BlockTracer/`
(see `BlockTracer.milestones.org` and `BlockTracer-Overview.md`).

## Status

Scaffold. Implementation begins with the demo-first decoupling seam:

- **M5b — Data Contract**: the versioned contract between the chain-extractor and
  the site-generator, plus a conformance validator.
- **M5c — Demo Data Generator**: a fake extractor/trace-gen that emits a valid,
  Aztec-shaped static tree honouring the contract.

The house language is Nim (as in isonim, codetracer-nim and the recorder fleet).
No third-party dependencies — the Nim standard library only.
